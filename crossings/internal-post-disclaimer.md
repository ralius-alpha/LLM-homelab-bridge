# 社内投稿用 冒頭文言テンプレート

> Zenn記事等を社内（Teams・掲示板など）で共有する際、
> 投稿の冒頭に貼り付ける注意書きの原本。

###############################
# [IMPORTANT] このファイルの役割 #
###############################

- Public リポジトリ（`LLM-homelab`）の記事本体には業務利用不可を書かない
- 代わりに、社内へ共有する投稿の冒頭に、この文言を貼る
- 「業務外の個人活動である」ことを社内向けに明示するのが目的
- 文言を勝手に弱めない（社内アリバイ・予防線のため）

---

## 標準版（社内投稿の冒頭に貼る）

社内Teams・掲示板でZenn記事を共有する時、投稿の冒頭に以下を貼る。

```markdown
###############################
# [IMPORTANT] 業務利用不可     #
###############################

以下で共有する記事は、私の業務外の個人活動（趣味・自己研鑽）です。

- 業務データ（コード、ドキュメント、議事録、顧客情報等）の投入は禁止
- 業務利用に転用する場合は、所属組織のセキュリティ部門への申請が必須
- 本内容は個人の自己研鑽・技術トレンドキャッチアップを目的としています

本記事は筆者の業務外活動として作成されており、
所属組織の見解とは一切関係ありません。
```

## なぜこれを徹底するか（自分用メモ）

[NOTE] この文言は、社内で安全に共有し続けるための生命線。

- 「業務外の個人活動」であることを社内に明示する
- 万一のインシデント時、責任範囲を限定する
- 業務利用と誤解されるリスクを下げる
- 「線引きができている人」という信頼を作る

文言を弱めたくなっても弱めない。共有のたびに必ず入れる。

---

## 運用メモ

- Public 記事側（Zenn/GitHub）には、この業務利用不可文言は載せない
- Public 側には軽い免責（自己責任・情報鮮度）のみ記載済み
- 役割分担:
  - Public = 社外向け（軽い免責のみ）
  - 社内投稿 = この文言を冒頭に貼る（業務利用不可の明示）
